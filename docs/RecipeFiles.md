# 工艺参数文件与功率曲线

## 分层

- `Models/ProcessRecipe.cs`：工艺文件数据、材质 / 厚度 / 喷嘴 / 气体 / 焦点 / 时长、基础激光参数、功率曲线节点、校验与线性插值。默认模板由模型工厂生成。
- `Models/SimulationParameters.cs`：Mock 节拍、回零步数、空移步数、XY 行程、点动速度、冷却水温和示例孔阵列参数。
- `Models/MachineModels.cs`：孔位、加工状态枚举、运行事件数据。
- `Services/RecipeFileService.cs`：文件加载、默认文件生成、旧数据迁移、原子保存和唯一当前工艺快照。
- `Services/MockDrillingMachine.cs`：依据已应用的快照运行，模拟孔间移动、出光阶段及随进度变化的功率。
- `ViewModels/RecipeLibraryViewModel.cs`：编辑字段、草稿状态、节点编辑命令、保存 / 应用命令。没有硬编码的模拟工艺模板，也不直接读写 JSON。
- `Views/PowerCurveEditor.cs`：曲线绘制、节点拖动输入；插值不在视图中实现。

`LocalAccountService` 保留早期参数 API 兼容入口，委托 `IRecipeFileService`；工艺数据不再写入账号文件。旧账号文件中的参数和工艺首次初始化时迁移，密码与账号数据不改写。

## 文件与加载

正式运行数据目录为 `%LOCALAPPDATA%\LaserDrilling`：

```text
LaserDrilling/
  accounts.json             账号数据
  active-recipe.json        唯一当前工艺完整快照
  Recipes/
    .initialized            初始化/迁移标记
    recipe_DEFAULT_....json
    recipe_用户工艺名_....json
```

进入加工系统会读取当前工艺；进入参数库加载目录下全部 JSON。没有 JSON 时自动生成内置默认文件；遇到不合法文件时保留原文件、跳过该项并在参数库底部列出文件名。不在有损坏文件的目录中静默覆盖或伪造“恢复成功”。若当前快照本身损坏，会报错而不悄悄换用其他工艺。

默认模板是 Mock 示例，不代表任何材质的验证工艺。默认曲线为升功率、保持、降功率；迁移旧固定功率工艺时保留其固定功率含义。

## 操作

1. 管理员打开工艺参数库，点击“从默认模板新建”。
2. 填写工艺名称、材质、厚度及相关参数；编辑功率曲线。
3. 点击“保存工艺”：写入独立文件。同名保存覆盖文件内容，不替换当前加工快照。
4. 点击“应用所选工艺”：显式切换当前加工指定工艺，主页显示该名称。

有未保存草稿时禁止切换文件及应用；可保存或放弃草稿。操作员只读；运行 / 暂停 / 回零 / 手动移动期间禁止编辑与应用。工艺库使用主窗口中央公共视图区；切换页面保留草稿，不会自动保存，退出登录释放草稿。

## 功率曲线语义

横轴为**每个孔的出光阶段进度** 0–100%，不是整件工件进度、平台速度或深度。纵轴为设备功率百分比，受峰值功率上限约束。所有孔复用当前工艺的同一曲线。

节点 2–32 个，必须包含 0% 与 100% 两端，进度严格递增，功率为 0–峰值上限。鼠标拖动节点或修改节点数值后点击“更新节点”；支持增加中间节点和删除中间节点。相邻节点线性插值。

Mock 使用 `DwellMilliseconds` 决定每孔出光阶段时长，采样节拍由 `SimulationParameters` 定义。频率、脉冲数、喷嘴、气体、气压、焦点等是保存的工艺设定，不代表本版已实现相应硬件物理模型。孔间移动、暂停、停止、故障与空走均输出零功率；空走也关闭气体。运行时的工艺快照保持不变。

## 验证

`work/StartupSmoke` 使用隔离临时账户和文件目录，覆盖默认文件生成、多个材质文件保存和重载、损坏文件提示、当前快照与库文件隔离、重新登录持久化、非法曲线拒绝、节点编辑保存、显式应用、权限限制、模拟功率变化、空走零输出及顶栏时钟。渲染中英文、深浅主题和最小主窗口布局。

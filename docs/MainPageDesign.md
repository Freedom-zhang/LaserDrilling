# 激光打孔主界面：现代 HMI 工作台

## 需求与范围

依据用户提供的 WPF HMI 试题，实现设备状态、加工工作区、工艺参数、回零与加工控制、报警事件。采用现有 .NET 8 / WPF / Prism / HandyControl，延续中文英文、深浅主题及本地角色权限。

场景限定为单件装夹的激光微孔加工；没有虚构生产任务队列。加工工作区是默认主页；设备状态、加工工作区、工艺参数库、报警 / 日志共用中央视图区，仅系统设置打开独立窗口。所有设备数据均为模拟。

## 调研参考

- [星驰激光产品中心](https://starlaser.tech/jgzb)：结合其精密微加工、振镜加工产品方向确定“孔位、工件坐标与光斑”的主要业务对象。
- [华工激光振镜精密切割智能装备](https://www.hglaser.com/product/pro-detail-189.htm?c=142&n=1&p=132)：参考振镜设备对打孔、定位、图形及光源工艺的组织方式；不采用该厂商参数作为本项目设备规格。
- [柏楚 CypCut 官方产品介绍](https://www.bochu.com/ch/soft/cypcut/?instructions=true)：借鉴图形工作区与加工控制栏并列、坐标与加工控制集中显示的信息组织。CypCut 属于切割软件，本项目只参考布局，不照搬切割工艺。

这是独立设计的设备原型，不是任何厂商官方软件的复刻，也没有使用其商标或界面截图作为素材。

## 信息布局

1. 最左侧：设备状态、加工工作区、工艺参数库、报警 / 日志、系统设置五个垂直入口，本地矢量图标；底部退出登录。全宽顶栏左侧显示 Logo 和产品名称，右侧集中显示账号、时间、模拟提示及三组设备状态。
2. 左栏：单件程序信息、孔位列表、管理员孔位编辑。默认 24 孔只是示例，可增删到 200 孔，可改变 XY、孔径、目标深度。
3. 中央：100 × 80 mm 工件坐标视图、空移顺序、选中孔、完成孔及模拟光斑；支持滚轮缩放、点击选孔及适应视图。
4. 右栏：实时坐标、激光 / 气体输出、八方向 XY 轮盘、Z 上下点动、速度倍率、光闸、红光、出光测试、跟随、吹气、回零、走边框、空走、加工、暂停、停止、模拟急停。运动参考、安全门、冷却水及故障注入放入设备状态页。
5. 工作区下方仅保留工艺摘要、进度、当前孔、用时；移除日志滚动区域。日志页显示最多 200 条当前会话事件。

采用固定分区、窄边框、紧凑表格和带单位的数值，扩大中央加工区域。工作区保持深色，外围面板随主题切换。中英文和主题切换集中在系统设置窗口。主窗口最小布局为 1180 × 740 DIP。系统设置为主窗口拥有的非模态窗口，重复点击激活已有窗口。其他页面在中央视图区切换，右侧控制台始终保留。页面缓存限当前登录会话，切换保留工艺草稿；退出登录后释放视图模型。

## XY 轮盘与空走

轮盘按住方向持续移动，支持八方向与 XY 斜向联动，100% 倍率下合速度为 5 mm/s，倍率可调 10%–100%。松开、移出、失去鼠标捕获、窗口失活、Escape 或故障均停止；未回零及加工运行期间禁止手动移动。坐标限制在模拟的 100 × 80 mm 工作区，十字光标同步移动。

空走参考[柏楚 HypCut 加工和空走说明](https://www.bochu.com/knowledge/hypcut-%E5%8A%A0%E5%B7%A5%E5%92%8C%E7%A9%BA%E8%B5%B0/)中沿加工路径运动但关闭激光、气体的原则。本版沿孔位顺序模拟，可暂停、继续、停止；显示“经过孔数”，经过孔以蓝色标识，不新增加工完成标记。所有节拍为演示，不模拟真实加减速与跟随控制。

工艺库支持按材质、厚度命名保存独立 JSON、同名覆盖和应用所选工艺；保存与应用是分开的动作。管理员才可修改，运行与手动移动期间禁止修改；操作员可查看。当前工艺另存唯一快照，详细机制见 [工艺文件与曲线说明](RecipeFiles.md)。

Logo、登录用户与每秒刷新的时间现在位于跨全宽的独立顶栏，左侧仅保留导航；顶栏右侧常驻显示设备连接、激光器与运动系统状态。

## 操作与状态

典型流程：登录 → 检查状态及孔位 → 回零确认 → 回零完成 → 启动确认 → 逐孔模拟 → 完成。

- 普通操作：选孔、缩放、查看日志、语言与主题切换，直接响应。
- 重要操作：回零、启动、故障复位使用居中确认层，明确操作后果；取消不改变设备状态。
- 危险/中断操作：停止使用红色，点击立即停止当前模拟过程。模拟急停使用更醒目的红色并锁存故障，不增加延迟确认。
- 开门故障：立即关闭模拟出光、停止运动、取消参考状态。关门后仍需复位，再重新回零，绝不自动恢复加工。
- 暂停：保持当前孔进度，禁止出光；继续后恢复当前任务。停止后再次启动从首孔重新加工。
- 运行、暂停、回零期间：锁定孔位与工艺编辑、系统设置及退出登录；仍可切换查看中央页面；停止后恢复。
- 管理员可编辑孔位及保存参数；操作员可启动已准备的模拟任务、暂停和停止，但不能编辑孔位或保存工艺。

## 实现结构

- `MockDrillingMachine`：模拟设备状态及联锁、孔位集合、事件、逐孔进度；100 ms UI 调度节拍，提供可直接步进的 `Advance` 用于确定性验证。
- `DrillingViewModel`：Prism 命令、确认流程、选孔与编辑输入校验。
- `DrillingView`：布局与绑定；代码后台仅处理视图复位。
- `DrillingViewport`：WPF DrawingContext 矢量绘制、鼠标缩放与命中测试，没有加工算法。
- `WelcomeViewModel` / `WorkspaceWindows`：工作台、独立窗口复用与会话生命周期；离开时关闭子窗口并释放模拟计时器。
- `JogWheel`：八方向鼠标输入、捕获和停止释放；`RecipeLibraryViewModel`：工艺保存与应用。
- `LocalAccountService` / `AccessPanelViewModel`：复用本地账号和工艺存储、角色限制。
- `MachineVocabulary`：中英文主页面文案，接入既有 `AppearanceService`。

## 模拟边界与未完成项

没有实际 CAD 导入、设备协议、硬件急停、真实视觉定位、振镜校正、实时加工轨迹或深度闭环。Z 显示模拟焦平面，孔深是目标元数据；XY 表示概念化的工件光斑位置，不代表已分离建模的平台与振镜位置。当前节拍固定用于演示，不依据激光工艺计算真实加工时长。

命名工艺数据保存到现有本地账号数据目录，孔位和日志仅保留本次登录会话，编辑时明确提示未保存。冷却水使用固定模拟值。后续可补充任务文件导入导出、加工记录持久化、联锁接口、可校准的坐标变换与设备通讯。

软件中的“模拟急停”只演示交互，不是硬件安全回路，也不能用于保护真实设备。

## 验证

### 对比度与第三方控件

提高标签文字、输入框边界、表格分割线和选中项对比度；数值采用加粗等宽字体。深色模式将亮色信息强调与深色按钮底色分开，避免白字置于过亮按钮背景。

HandyControl 的 NumericUpDown 用于孔位、工艺和曲线节点输入；Tag 用于常驻状态；Badge 提示当前锁存故障；按钮基于库的 ButtonPrimary 模板。状态同时使用文字和颜色：绿色就绪，蓝色运动 / Mock 通信在线，琥珀色待回零 / 暂停 / 出光，红色联锁故障，灰色待机 / 停止。Mock 在线始终注明真实硬件未连接。

参考：[HandyControl NumericUpDown](https://handyorg.github.io/handycontrol/extend_controls/numericUpDown/)、[Tag](https://handyorg.github.io/handycontrol/extend_controls/tag/)、[Badge](https://handyorg.github.io/handycontrol/extend_controls/badge/)。控件按本项目 3.5.1 实际 API 编译验证，保留独立服务校验及运行期锁定。

扩展 `work/StartupSmoke` 检查：回零前禁止启动、重要操作确认/取消、逐孔进度、暂停冻结、停止关光、开门锁存、复位条件、急停、完成 100%、孔位数量编辑、运行期编辑锁定、管理员/操作员切换与服务权限。另渲染浅色、深色、最小窗口英文及故障状态，进行布局检查。

## 单功能模拟与 Z 轴

- Z 轴范围为 -50～50 mm。按住 Z↑/Z↓ 移动，松开、移出、丢失鼠标捕获、窗口失活或 Escape 停止。跟随开启后禁止手动 Z；跟随仅将 Z 设置为当前工艺焦点偏移的限幅值，不模拟真实传感器。
- 光闸、红光和吹气显示琥珀色激活状态。出光测试要求已回零、光闸打开、红光关闭和联锁正常，经确认以 5% 模拟功率运行 0.5 秒，然后自动关闭出光与光闸。
- 走边框沿孔位包络外扩 2 mm 的矩形移动（裁剪至工作区），只开启红光指示，不出光、不吹气，不改变孔完成标记与数量。工作区显示红色虚线边框和移动光标。
- 停止可终止运行、走边框、出光测试和手动输出；安全门或模拟急停关闭输出并锁存故障。
- 模拟时长、Z 限位、速度和测试功率在 `Models/SimulationParameters.cs`；状态机及联锁在 `MockDrillingMachine`；ViewModel 只负责命令、确认及绑定。不存在硬件通信。

验证覆盖中央页面复用、工艺草稿保留、Z 按钮按下/松开与限位、跟随锁定 Z、出光条件与自动结束、门联锁中断、边框运动零出光/零吹气及停止；保留原有权限、曲线、空走与登录回归测试。
